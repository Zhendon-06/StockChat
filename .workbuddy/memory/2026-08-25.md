## 聊天输入区 UI 修复（3 文件：StockChatPage/StockChatComponents/StockChatLayoutMetrics）

1. **语音模式右下角灰色圆形残留**：根因是发送按钮用 width/opacity + `animate` 收起，进入语音模式（先聚焦再切语音）时收起不生效，残留 42dp 灰圆并遮挡加号按钮。改为 `vif({ composerFocused && !voiceMode })` 整体挂载/移除；并在 `inputFocus` 中防御：语音模式下若异常聚焦则立即 blur，不再将 voiceMode 置回 false。
2. **用户气泡多行换行**：Kuikly Text 只有在自身宽度确定（width/flex）时才折行，shrink-to-fit 容器里 maxWidth 不会触发折行（已读 core-2.7.0 源码 TextView.measure 确认不处理 styleMaxWidth）。方案：新增 `estimateWrappedLineCount()`（CJK≈字号宽，拉丁≈0.56×字号），估算超宽时给 Text 设确定 width(258*scale)。
3. **输入框多行自适应增高**：新增 `inputLineCount` observable（最多 5 行），textDidChange/inputFocus/focusTextInputAfterLayout 中重算；TextArea 高 = 15 + 23×行数；metrics 三个 composer 高度函数新增 extraInputLines 参数；sendMessage/startNewChat 重置行数。
4. **附带修复**：顶部会话标题溢出遮挡胶囊按钮 → 设确定宽度 + lines(1) 截断。

验证：`:shared:compileDebugKotlinAndroid` + `:androidApp:assembleDebug` 通过（31s）。真机语音交互与多行视觉效果未回归验证。

## 抽屉历史列表修复（StockChatPage.kt）

1. **选中高亮固定在第一项**：根因 `activeSessionId` 声明为普通 var（非 observable），列表项 attr 读到它但不建立响应式订阅，高亮只在首次渲染（默认第一个会话）时计算。改为 `by observable("")` 后，selectSession/startNewChat 切换会话时高亮自动跟随。
2. **新建对话与分割线的间距过大**：分割线上方 marginBottom 18 → 8，"新建对话"行 marginTop 8 → 2，总间距从 ~26dp 收到 ~10dp。

验证：`:shared:compileDebugKotlinAndroid` + `:androidApp:assembleDebug` 通过（28s）。
