## 修复"收起键盘时部件从左上角飞入"（根因：vif 重挂载 + 父容器布局动画时钟）

- 根因：Kuikly `animate(animation, observable)` 会在 observable 变化时对视图子树跑布局动画；被 `vif` 重新挂载的视图没有旧帧，会从零点帧（父容器左上角）动画到目标帧 → 视觉即"从左上角飞入"。
- 触发链：键盘弹起/聚焦 → `WelcomeObscuredChanged(true)` → `vif` 卸载欢迎内容；收起键盘 → `vif` 重挂载，正撞上父容器 `animate(easeOut(keyboardAnimDuration), keyboardHeight)` 的动画时钟 → hero/标题/推荐 chips 集体从左上角飞入。
- 修复模式（通用）：**vif 只保留在"阶段切换"级条件；"显隐"级条件改为常驻挂载 + `opacity` 淡入淡出 + `touchEnable(visible)`**。修了三处：
  1. 欢迎内容 `HomeContentLayer`：`vif(WELCOME && !obscured)` → `vif(WELCOME)` + 内层 wrapper `opacity/animate(easeInOut 0.24f, welcomeObscured)`。
  2. 图片附件条（ComposerDock 内，`vif(selectedImageCount>0)`）→ 常驻 + `animate(easeInOut 0.2f, selectedImageCount)`。
  3. 语音模式提示 Text（`vif(voiceMode)`）→ 常驻 + `opacity(voiceMode)`（复用已有 voiceMode 动画注册）。
  4. 会话层（二次排查补充）：`sendMessage` 里 `dispatchHome(QuestionCommitted)` 切 CONVERSATION 后紧接 `blur()` 掉键盘，`vif(CONVERSATION)` 挂载 MessageList/渐变层/ConversationHeader 会撞上键盘动画时钟 → 两个 `vif(CONVERSATION)` 与 `vif(WELCOME)` 全部改为常驻 wrapper + `opacity` + `animate(easeInOut 0.24f, chatStage.ordinal)`，欢迎层额外注册 `welcomeObscured` 键。
- 排查结论：内容区/输入坞内所有"显隐级 vif"已清零；剩余 vif（会话列表空态、重命名弹窗、遮罩层、managingSessions、菜单）的父容器均无相关动画时钟，安全。
