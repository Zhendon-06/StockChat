# 个股行情详情

行情页面由 `StockMarketPanel` 实现，保持 Kuikly commonMain 组件、聊天结果参数路由和原有 AI 预测入口。

## 展示与交互

- 价格及涨跌额/涨跌幅、今开/最高/最低/昨收、量额、换手率、量比；展开查看更多振幅、估值及市值信息。
- 分时、五日、日 K、周 K、月 K 使用对应接口返回的数据。K 线请求 240 根，初始展示最近 60 根；支持点选、缩放、横向平移和双击复位。
- K 线叠加 MA5/10/20，价格与成交量共享横轴、视口和选中位置；均线使用完整历史预热。
- 分时为蓝色价格线、黄色成交均价，左侧价格、右侧相对昨收涨跌幅。交易时段按 A 股/港股处理，休市时间不占横轴，尚未交易时段留白。
- 分钟接口的量额是累计值。成交量先求差分，个股成交均价按累计金额/累计股数计算；A 股手数转换为股数，港股使用股数。指数成分股的量额不能换算成指数均价，因此指数只显示点位走势，避免错误均价拉大坐标范围、压平曲线。缺失值保持缺失，重置量不生成负柱。
- 五档盘口提供买卖报价、数量和五档委比，不支持的标的显示暂无数据。
- 资金数据可用性不足，详情页已关闭「资金」入口及内容展示，进入页面不再请求资金数据。个股保留「盘口 / 简况」，指数保留「概览 / 简况」。
- 行情有加载、无数据和失败重试状态。周期切换使用请求代次过滤过期响应，页面销毁后忽略回调。

## 数据边界

`StockMarketDetailDataSource` 隔离数据访问，可替换为其他行情服务或 mock 实现。腾讯证券提供价格、K 线、分时、盘口。东方财富资金接口及展示实现暂时保留，但详情页不再调用或展示；以下资金说明仅记录保留实现的口径。

资金接口只提供各单规模的**净额**，不能反推出主力/散户的买入、卖出总额。现在以各类净额的绝对值计算环图占比，明确标注净额口径；不把它解释为买卖成交占比。接口失败或空数据时，可主动选择资金演示样例，展示参考图的主力/散户流入流出环图。该样例独立标明万向德农 600371、非实时和演示身份，退出后重新请求真实数据；请求代次防止迟到的真实行情混入样例。双轴图使用日频对照，未将日频数据伪装为分钟资金走势。当前未提供逐笔行情推送、交易下单或分钟 K 线。

## AI 预测与主要指数

- AI 走势已改为 `FinancialChartMode.CLOSE_LINE`，删除旧 Canvas 绘图。历史日线为实线，未来估计为虚线；分界、预测区间阴影、日期点选、缩放和平移使用同一个组件。
- 区间只展示模型明确返回且有效的上下界，不补造缺失区间；没有历史锚点时不显示预测。历史缓存保证切换模型加载时图表稳定。
- 模型账户欠费/额度不足使用中文可操作提示；当前阿里云账户返回欠费，真实预测成功态尚未完成端到端验证。图形成功态已在 Android 手机上通过组件 `financial_preview` 的明确演示样例检查，虚线、区间阴影及环图正常显示。
- 今日市场主要指数卡片使用独立纵轴及真实日线收盘序列，明确显示数据周期和范围；涨跌分布环图仅统计四个主要指数，不代表全市场股票涨跌家数。
- 指数详情隐藏不适用的个股盘口/资金入口。通用图表纵轴边距按格式化标签的实测宽度分配，修复深证成指五位数点位首位被裁切的问题。

## 图表组件接入

先在本地 KuiklyChartView 仓库的 `kuikly-chart` 模块开发金融组件，再使用 `tools/sync-chart-component.sh` 同步到本项目。保留一份可独立构建的源代码模块，不依赖开发者机器上的绝对路径，也不需要发布临时 Maven 版本。

```sh
./tools/sync-chart-component.sh ../KuiklyChartView
```

脚本只同步 commonMain/commonTest 和模块构建定义。StockChat 使用自己的 Kuikly 2.26.0 / Kotlin 2.1.21；原组件仓库保持 Kuikly 2.7.0 / Kotlin 2.1.21。金融组件使用两者兼容的公共 API，Android、iOS、JS 和鸿蒙的源码均位于 commonMain。

## AI 结论反向定位

- 日/周/月 K 图下方提供带日期区间的本地演示解读。点选某根 K 线后，解读改为截至该点的最近至多 5 根 K 线，文字按实际首尾收盘价生成，不预设上涨。
- 点击「查看对应区间」，组件自动调整视口，完整显示引用区间及相邻上下文；价格图、成交量图同时显示阴影、虚线边界和「依据区间」标签，并列出完整日期、指标和 K 线数量。支持清除高亮；点选、缩放、横拖、复位、切换周期会清除旧高亮。
- 远程 AI 预测新增 `conclusions` 数组，每条包含 `text` 与 `reference`，例如：

```json
{
  "text": "近几个交易日区间末收盘价较起点回升",
  "reference": {
    "symbol": "600519",
    "period": "day",
    "startDate": "2026-09-02",
    "endDate": "2026-09-08",
    "metric": "close",
    "sourceUpdatedAt": "原样回显输入行情时间"
  }
}
```

- 模型仅获得历史收盘价，因此当前提示词仅允许 `day` / `close` 引用。界面先对输入历史校验，点击后切回行情日 K，并对加载的 OHLC 数据再次校验。没有结构化引用时继续显示文字并提示不可定位，兼容旧模型响应。
- `ChartEvidenceResolver` 严格检查标的、周期、行情版本、真实日历日期、端点存在性、顺序及指标可用性；拒绝未来或缺失交易日、重复或乱序数据、非法数值。不解析结论中的自然语言，不取最近日期，不裁剪越界范围。公共解析器预留 `volume`、`MA5/10/20`，并检查缺失量和均线预热长度。
- 日期校验仅确认图表定位依据存在，不表示已验证模型结论或预测正确性。行情接口加载失败/空数据时沿用重试入口，尚未完成的定位随重试继续；手动切换周期和页面销毁后不应用旧请求。
- 已加载数据带独立周期标识，防止切换缓存周期时将上一周期的数据绘制到新周期图中。
